# STM32 EASY FLASH has no third-party Python dependencies.
#
# Everything it imports is part of the Python standard library:
#   tkinter, urllib.request, zipfile, tarfile, shutil, subprocess,
#   threading, argparse, platform, os, sys, queue
#
# Nothing needs to be installed via pip. Run:
#   pip install -r requirements.txt   # installs nothing
#
# Note: tkinter ships with CPython but is packaged separately on some
# Linux distributions, e.g.:
#   sudo apt install python3-tk        # Debian / Ubuntu
#   sudo dnf install python3-tkinter   # Fedora
